### Fixed

- The systemd D-Bus client no longer crashes when a socket deadline or close lands mid-message (godbus v5.2.4). (#215)

godbus v5.1.0's `DecodeMessageWithFDs` ran `dec.align` outside the recovered decoder when a read failed, so a socket close or deadline that landed mid-message panicked instead of returning the read error. v5.2.4 performs that padding read through the error-returning path, so the read error is handled instead of crashing the systemd service client.

- README rendering uses a patched `golang.org/x/net` (GO-2026-6866, GO-2026-6860), and the build toolchain moves to Go 1.26.11. (#216)

The two `x/net/html` advisories reachable from README rendering are fixed in `golang.org/x/net` v0.63.0, which the build now uses. The build toolchain also moves to Go 1.26.11, which includes the `net/http` fix for GO-2026-6859.
