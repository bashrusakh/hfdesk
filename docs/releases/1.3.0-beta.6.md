### Fixed

- A download reports `writing` only while file creation/preallocation or a payload write is in flight, and its speed/ETA come from network reads; a completed write or a pure network stall does not hold that phase. (#209)

On an NTFS volume, creating the 8 GB target file ran at about 100 MB/s for roughly 80 s before any network byte arrived, while the job card showed about 2 KB/s, decaying, and an ETA that kept growing into hours. The download speed and ETA now derive from the response-body bytes read in this run, `writing` is held only while local work is in flight, and the ETA clock starts at the first read.

### Changed

- The selected GGUF group deletion confirmation names the quantization in its title and shows left-aligned facts, a one-sentence scope, and file rows with right-aligned sizes; the whole-copy confirmation is unchanged. (#207)

The confirmation title now names the quantization, the facts sit in a left-aligned grid with a one-sentence consequence, and the file rows carry right-aligned sizes. The whole-copy confirmation is unchanged.
