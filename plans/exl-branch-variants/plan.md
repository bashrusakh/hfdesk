### Shared ownership/admission model to implement (invariant; schema/mechanism remain engineering-owned)

4. **No name-based recursive reservation:** recursive effect preflight discovers and protects only descendant service roots whose logical owner evidence validates. A per-root OS-private ephemeral lock object is a fallback candidate if directory-handle locks are not adequate; it avoids a cache-visible reserved filename but adds private-key/cleanup mechanics that must remain stable across aliases and safe on process exit. A public cache sidecar such as `.hfdesk-rebuild.lock` is disproven by the accepted ordinary-writer collision and must not be reserved/clobbered. The preferred bounded model is therefore logical-owner validation plus current-physical-object locking, using a validated copy rebind (or equivalent separation) and the narrowest viable private/handle lease; exact schema and OS primitive remain implementation-owned, not a product choice.

If current owner/control records do not provide enough structural evidence to recognize a valid copy while keeping malformed/unattributed data unadopted, return the exact missing evidence/precondition to the parent before changing the compatibility contract.
